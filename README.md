# Plazo fijo · Presentación del caso

Presentación interactiva del caso de estudio "¿Y si invertir empezara por explorar?".

**Ver:** https://ricardofalcondev.github.io/presentacion-plazo-fijo/

- 12 slides en 16:9 (1920 × 1080) que se escalan a la pantalla.
- Navegación: flechas ← →, barra espaciadora, clic en los costados, swipe; `Esc` abre el índice; `#n` en la URL abre la slide n.
- Slides 9 y 10 embeben el [prototipo](https://ricardofalcondev.github.io/prototipo-plazo-fijo/) en vivo.
- Construida con el sistema de diseño del caso (tokens de color, espaciado, radios y elevaciones) y una escala tipográfica de presentación.
- Textos editables en `src/content.js`. Diseño editable en Figma, página "🎤 Presentación".

Stack: Vite + React + Framer Motion. Se publica con GitHub Pages en cada push a `main`.
